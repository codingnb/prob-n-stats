Project #2: Dice simulator

Requirements:
Ask the user how many dice rolls they want
Generate a random number from 1–6 like on a 6 sided dice
Count how many times each number appears
Print the results
Calculate the percentage for each number
Let the user run another experiment


Project #3: Number Guessing Game

Requirements:
Generate a random number from 1–100
Ask the user to guess the number
Tell them if their guess is too high or too low
Keep letting them guess until they get it
Count how many guesses they needed
Let the user play again

New stuff: while loops, comparison logic, better user interaction.


Project #4: Probability Experiment

Requirements:
Ask the user how many experiments they want to run
In each experiment, flip a coin 10 times
Count how many experiments get:
0 heads
1 head
2 heads

10 heads
Print how often each result happened
Calculate the percentage for each result
Let the user run another experiment

Challenge:
Compare your results to what you expect mathematically.

New stuff: nested loops, probability distributions, organizing data.


Project #5: Monte Carlo Pi

Requirements:
Ask the user how many random points to generate
Generate random (x, y) coordinates between 0 and 1
Determine whether each point falls inside a quarter-circle
Count how many points are inside
Use that to estimate π
Print:
Number of points
Points inside
Estimated π
Difference between your estimate and actual π
Let the user run another experiment

Challenge:
Try 100, 1,000, 10,000, 100,000, and 1,000,000 points.

See how your estimate changes.

New stuff: Monte Carlo simulation, coordinates, mathematical modeling.

Project #6: Stock Price Simulator 📈

Not real trading — you're going to create your own fake market.

Requirements:
Ask the user how many days to simulate
Start a stock at $100
Each day, randomly change the price
Store every day's price
Print the price for each day
Calculate:
Starting price
Ending price
Highest price
Lowest price
Total percentage change
Let the user run another simulation

Challenge:
Make the price changes somewhat realistic instead of just randomly picking any price.

New stuff: lists, functions, data analysis, randomness, basic financial modeling.
